# Legacy-версия расписания КГУ (Vanilla JS)

Архивная версия клиента расписания, построенная на чистом HTML, CSS (Bootstrap 5) и Vanilla JavaScript (ES-модули без сборщика).

## Структура

- `index.html` — страница приложения
- `styles.css` — стили и поддержка Telegram-темы
- `logo.svg` — логотип КГУ
- `js/` — клиентские ES-модули:
  - `app.js` — инициализация и обработка событий
  - `students.js` — выбор группы и расписание студентов
  - `teachers.js` — выбор преподавателя и расписание преподавателей
  - `renderer.js` — отображение пар и дней недели
  - `storage.js` — работа с кэшем и сохранёнными группами
  - `platform.js` / `telegram.js` — интеграция с Telegram WebApp
  - `utils.js` — вспомогательные функции и даты

## Запуск

Архивную версию можно запустить любым статическим веб-сервером из корня проекта:

```bash
# Из корня репозитория tksu_schedule:
python -m http.server 8080
```
Затем открыть: `http://localhost:8080/legacy/`

Данные загружаются относительно из каталога `../data/`.
