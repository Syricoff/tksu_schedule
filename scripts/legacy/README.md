# Архивные версии скриптов загрузки данных (Legacy Scripts)

В этой папке сохранены исторические версии скриптов загрузки расписания с API APEKS:

- `fetch_data_v1_sync.py`: Исходная синхронная версия на `requests`. В ней отсутствовал точный rate-limiter, что приводило к ошибкам HTTP 429 при повышенной нагрузке на API.
- `fetch_data_v2_async.py`: Экспериментальная асинхронная версия на `asyncio` и `aiohttp` с адаптивным управлением скоростью.

## Актуальный скрипт

Основной рабочий скрипт находится в корне каталога скриптов:
👉 `scripts/fetch_data.py`

Особенности актуального скрипта:
- Потокобезопасный Token Bucket rate limiter (по умолчанию 4 запроса/сек);
- Пул из 6 рабочих потоков (ThreadPoolExecutor) с keep-alive сессиями;
- Экспоненциальный backoff с jitter и уважением заголовка `Retry-After`;
- Атомарная запись JSON-файлов через временные файлы (`.tmp`);
- 100% совместимость со структурой `data/`.
